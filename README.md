# THE CONSTRUCT

Matrix-style first-person shooter that runs in the browser. The game core is
written in Rust and compiled to WebAssembly; three.js renders it.

**Play it:** https://the-construct.kevin-128.workers.dev

## How to play

The start screen plays the "Wake up, Neo…" intro (click to skip it) and then
offers a choice: take the red pill to jack in, or take the blue pill to wake
up in your bed and believe whatever you want to believe (it drops you into
the dream sequence, then back to the choice). The page grabs your mouse; press
Escape to release it. The simulation freezes while the menu is up, and a
click resumes it. When a run ends, the result and a red pill to reinitialize
appear on the same menu.

| Key | Action |
|-----|--------|
| Arrow keys or WASD | move |
| Mouse | look |
| Left click | fire |
| Shift | sprint |
| Escape | pause / release mouse |
| M | mute / unmute audio |

1. **Ten levels.** Terminate every agent to clear a level. The panel in the
   top right tracks agents cleared for the current level.
2. **Each level sends more agents, faster.** Agents take two hits; tougher
   ones with extra hit points appear from level 5 on. New agents flicker in
   over a moment and can't move or hurt you until they've materialized.
3. **Agents drain your integrity on contact.** The bar in the bottom left
   is your health. At zero, the system fails and you restart from level 1.
4. **Level 10 is the Architect.** One program, far more resilient, that hits
   harder and phase-shifts to a new position around you every few seconds.
   A health bar for it appears at the top of the screen. Delete it to win.

Sound starts on the first click. A procedural techno track plays under the
game and gets busier every level; bullet time slows it down and muffles it,
and the Architect gets its own darker pattern. Press M to mute; the choice is
remembered.

Buildings block shots as well as movement. Clearing a level drops the world
into bullet time for a few seconds while the next level loads; you keep
moving at full speed. Taking damage glitches the screen; occasionally the
system answers a kill with one of its one-liners as a subtitle ("There is no
spoon.", "Dodge this.", …).

## Layout

```
core/src/lib.rs     Rust game core: world generation, movement and collision,
                    enemy AI, raycast hit detection, levels, particles, rain
core/               Cargo crate (compiles to wasm32-unknown-unknown)
site/               everything that gets deployed, nothing else
site/index.html     thin three.js renderer that reads the core's f32 buffers
site/audio.js       Web Audio techno soundtrack and sound effects, all synthesized
site/index-js.html  the original pure-JavaScript version, kept for comparison
site/pkg/           wasm-bindgen output, generated by `npm run build`, committed
site/_headers       security headers (CSP etc.) applied by Cloudflare and wrangler dev
site/favicon.*      tab icon (the HUD crosshair); favicon.ico and apple-touch-icon.png are rendered from favicon.svg
build.mjs           cargo build + wasm-bindgen, writes into site/pkg/
wrangler.jsonc      Cloudflare Workers static-assets config
```

## Prerequisites

| Tool | Needed for | Install |
|------|-----------|---------|
| Rust toolchain (1.80+) | building the core | https://rustup.rs |
| wasm32 target | building the core | `rustup target add wasm32-unknown-unknown` |
| wasm-bindgen CLI 0.2.128 | generating JS bindings | `cargo install wasm-bindgen-cli --version 0.2.128` |
| Node 18+ and npm | wrangler | https://nodejs.org |

The wasm-bindgen CLI version must match the `wasm-bindgen` crate version
pinned in `core/Cargo.toml`. If you bump one, bump the other.

`site/pkg/` is committed, so you can run or deploy the site without a Rust
toolchain as long as you don't change the core.

## Build

```sh
npm run build
```

Compiles the core in release mode and regenerates `site/pkg/`. Run this after
any change to `core/src/lib.rs`.

## Run locally

```sh
npm install
npm run dev
# open the URL wrangler prints, usually http://localhost:8787/
```

This runs `wrangler dev`, which serves `site/` through the same Workers
runtime used in production, so what you see locally is what deploys.

Opening `site/index.html` directly from the filesystem will not work because
browsers block WASM and ES module loading over `file://`.

## Test

```sh
cd core && cargo test
```

The tests run natively and cover world generation, collision, shooting and
cooldown, enemy damage, the level-clear sequence, and the Architect fight.

## Deploy to Cloudflare

The site is served as a Cloudflare Worker with static assets. There is no
Worker script, just files.

First time only:

```sh
npm install
npx wrangler login
```

Then, whenever you want to publish:

```sh
npm run deploy
```

That runs the build and then `wrangler deploy`. The Worker is named by the
`name` field in `wrangler.jsonc`, which becomes the `*.workers.dev` subdomain.
Change it to deploy under a different name. Custom domains can be attached
from the Workers dashboard.

To validate the config without publishing:

```sh
npx wrangler deploy --dry-run
```

## How the Rust/JS split works

Each frame JS calls `game.step(dt, forward, right, sprint)` and gets back an
event bitmask (level start, level clear, hit, kill, death, damage). It then
builds `Float32Array` views over WASM linear memory for the state, enemy,
particle and rain buffers and copies them into three.js objects. Mouse deltas
go to `game.look()`; clicks call `game.fire()`, which raycasts against
buildings and agents in Rust and writes the impact point for the tracer. No
per-frame object allocation crosses the boundary; everything is flat f32
buffers and numbers.

During a level clear the core drops into bullet time and eases back over five
seconds while the renderer plays the code-rain overlay. Player movement stays
at real-time speed; only the world slows.

## Audio

`site/audio.js` synthesizes everything at runtime with Web Audio, so no audio
files ship. The soundtrack is a 4-bar, 16th-note step sequencer: kick, hats,
clap, a resonant acid bass line, chord stabs, an arpeggiated lead and a
filtered drone, with a generated reverb and a dotted-eighth dub delay. Layers
switch on as the level number rises and the tempo creeps up from 129 BPM. On
level 10 the root drops, the bass pattern turns to tritones and the stabs
land on every beat.

Each frame the renderer passes the core's time scale to the engine. The
sequencer step length, every oscillator's pitch and a master low-pass filter
all follow it, so bullet time sounds like a slowed tape. Pausing (releasing the
mouse) muffles the mix; death stops the sequencer and leaves the drone.

Sound effects map onto the core's event bits: fire, hit, kill, damage, level
start, level clear, death and win. Two more are detected renderer-side from
the enemy buffer, when a program's age resets to zero: a glitch tick when an
agent materializes and a reverse whoosh when the Architect phase-shifts.

From the console, `__construct.audio.fx.kill()` plays any effect and
`__construct.audio.level()` reports master RMS and peak.

A debug handle is exposed on the page as `window.__construct` for poking at
the core from the browser console, e.g. `__construct.level(10)` jumps straight
to the Architect and `__construct.win()` replays the ending.
